Deploy Locally

Get Up and Running in 2 Minutes

Self-host Billcraft on any standard LAMP/WAMP/XAMPP stack or Linux VPS.

# 1. Clone the repository into your web root (htdocs or /var/www/html)
git clone https://github.com/0xSHARON/billcraft.git
cd billcraft

# 2. Create the database and import schema
mysql -u root -p -e "CREATE DATABASE billcraft;"
mysql -u root -p billcraft < billcraft.sql

# 3. Configure your database credentials in connection.php
$con = mysqli_connect("localhost", "your_user", "your_password", "billcraft");

# 4. Open in browser at http://localhost/billcraft
# Default Admin Login: Username: admin | Password: admin
